## 1. 花括号初始化

C++11 引入了统一的列表初始化语法，可以使用花括号 `{}` 初始化变量：

```cpp
int a;       // 未初始化的局部变量，值不确定
int b{};     // 初始化为 0
int c{10};   // 初始化为 10

double x{};       // 初始化为 0.0
double y{3.14};   // 初始化为 3.14
```

对于普通局部数值变量，下面的写法不会自动将变量初始化为 `0`：

```cpp
int a;
```

如果在赋值前读取 `a`，程序会产生未定义行为。改用花括号初始化可以为变量提供明确的初始值：

```cpp
int a{};
```

花括号初始化还能阻止部分可能造成数据丢失的窄化转换：

```cpp
int a = 3.14;  // 通常可以编译，但小数部分会被丢弃
int b{3.14};   // 编译错误：不允许窄化转换
```

需要注意，`{}` 并不总是表示“初始化为零”。对于类和容器，花括号还可能匹配构造函数或 `std::initializer_list`，这部分可以在学习面向对象和标准容器时继续深入。

现阶段可以先养成一个习惯：定义基本类型变量时，优先给出明确的初始值。

## 2. 使用 cout 输出数据

C++ 的标准输入输出功能位于 `<iostream>` 头文件中：

```cpp
#include <iostream>
```

`std::cout` 是标准输出流对象，默认将数据输出到终端：

```cpp
int a{10};
double b{3.14};

std::cout << "a = " << a << '\n';
std::cout << "b = " << b << '\n';
```

输出结果：

```text
a = 10
b = 3.14
```

与 C 语言的 `printf()` 相比，`std::cout` 会根据数据类型选择对应的输出操作，不需要手动填写 `%d`、`%f` 等格式说明符。

### `\n` 与 `std::endl`

下面三种写法都可以产生换行：

```cpp
std::cout << '\n';
std::cout << "\n";
std::cout << std::endl;
```

它们的区别是：

- `'\n'` 是单个换行字符；
- `"\n"` 是包含换行符的字符串字面量；
- `std::endl` 不仅换行，还会立即刷新输出缓冲区。

普通输出通常使用 `'\n'` 即可，避免不必要的缓冲区刷新。只有确实需要立即显示当前缓冲内容时，才需要主动刷新。

## 3. 使用 cin 读取数据

`std::cin` 是标准输入流对象，默认从终端读取数据：

```cpp
int a{};
double b{};
double c{};

std::cin >> a >> b >> c;
```

在 C 语言中，类似操作通常写成：

```c
scanf("%d %lf %lf", &a, &b, &c);
```

C++ 的流输入不需要显式提供格式说明符，也不需要像 `scanf()` 那样手动传入普通变量的地址。`std::cin` 会根据目标变量的类型读取并转换输入内容。

## 4. std 命名空间与作用域解析运算符

C++ 使用命名空间组织名称，减少不同库或模块之间的命名冲突。标准库中的许多名称都位于 `std` 命名空间，例如：

```cpp
std::cout
std::cin
std::string
std::vector
```

其中：

- `std` 是 C++ 标准库命名空间；
- `::` 是作用域解析运算符；
- `std::cout` 表示访问 `std` 命名空间中的 `cout` 对象。

需要注意，`cout` 和 `cin` 都是对象，而不是函数。

作用域解析运算符也可以用于自定义命名空间：

```cpp
namespace Math
{
    int add(int a, int b)
    {
        return a + b;
    }
}

int main()
{
    int result{Math::add(2, 3)};
    return 0;
}
```

这里的 `Math::add()` 表示调用 `Math` 命名空间中的 `add()` 函数。

C++ 也允许写出：

```cpp
using namespace std;
```

这样可以直接使用 `cout` 和 `cin`，但也会把 `std` 中的大量名称引入当前作用域，增加名称冲突的可能。学习阶段建议保留 `std::`，尤其不要在公共头文件中使用 `using namespace std;`。

## 5. << 与 >> 为什么既能位移又能输入输出

在整数运算中，`<<` 和 `>>` 是位移运算符：

```cpp
int a{4 << 1};  // 左移一位，结果为 8
int b{8 >> 1};  // 右移一位，结果为 4
```

在标准输入输出流中，它们又有不同的含义：

| 运算符 | 整数运算中的含义 | 输入输出流中的含义 |
| --- | --- | --- |
| `<<` | 左移运算符 | 流插入运算符，用于输出 |
| `>>` | 右移运算符 | 流提取运算符，用于输入 |

例如：

```cpp
std::cout << a;
std::cin >> b;
```

这是因为 C++ 支持运算符重载。同一个运算符可以根据参与运算的对象类型执行不同操作：

- 两侧是整数时，执行位移运算；
- 左侧是输出流时，`<<` 执行流插入；
- 左侧是输入流时，`>>` 执行流提取。

本篇先理解标准库已经提供的流运算符重载。如何为自定义类编写运算符重载，可以在后续面向对象部分继续学习。

## 6. 流运算符为什么可以连续使用

输出语句可以连续插入多个值：

```cpp
int a{10};
double b{3.14};

std::cout << "a = " << a << ", b = " << b << '\n';
```

由于 `<<` 具有左结合性，这句代码可以理解为：

```cpp
((((std::cout << "a = ") << a) << ", b = ") << b) << '\n';
```

每次流插入操作完成后，都会返回输出流对象的引用。对于常见的标准输出流操作，返回类型是 `std::ostream&`，因此下一个 `<<` 可以继续操作同一个输出流。

输入操作也是同样的机制：

```cpp
std::cin >> a >> b >> c;
```

可以理解为：

```cpp
((std::cin >> a) >> b) >> c;
```

常见的流提取操作返回 `std::istream&`，所以后续的 `>>` 可以继续读取数据。

因此，流运算符能够链式调用，不是因为编译器先把所有数据拼成一个整体，而是因为每一步操作都会返回原来的流对象。

## 7. cin 如何处理空格、回车和制表符

使用 `std::cin >>` 读取整数、浮点数等数据时，默认会跳过前导空白字符：

| 空白字符 | 表示形式 | 常见来源 |
| --- | --- | --- |
| 空格 | `' '` | Space 键 |
| 换行符 | `'\n'` | Enter 键 |
| 制表符 | `'\t'` | Tab 键 |

对于下面的代码：

```cpp
int a{};
double b{};
double c{};

std::cin >> a >> b >> c;
```

以下输入方式都能得到相同结果。

使用空格分隔：

```text
2 3.4 5.6
```

使用回车分隔：

```text
2
3.4
5.6
```

混合使用多个空白字符：

```text
2

3.4    5.6
```

最终都会得到：

```text
a = 2
b = 3.4
c = 5.6
```

如果只输入 `2` 后按 Enter，程序不会直接结束，而会继续等待 `b` 和 `c`。对于格式化数值输入，换行符只是空白字符之一，并不表示整个输入表达式已经完成。

### cin 并不只是按空格切分文本

`std::cin >>` 属于格式化输入，会根据目标变量类型解析内容。

例如：

```cpp
int a{};
int b{};

std::cin >> a >> b;
```

如果输入：

```text
12abc
```

第一次整数提取能够读出 `12`，字符 `a` 会留在输入流中。接着读取 `b` 时，因为 `a` 无法解析为整数，输入操作失败，流会进入失败状态。

可以先记住以下结论：

- 读取数值时，`std::cin >>` 默认跳过前导空白字符；
- 空格、换行和制表符都可以分隔数值；
- 连续空白字符通常不会形成额外数据；
- 输入尚未完成时，交互式程序会继续等待；
- 内容无法转换为目标类型时，输入流会进入失败状态。

`std::getline()` 的行为不同，它通常用于读取一整行文本，并在遇到换行符时结束本次读取。

## 8. 检查输入是否成功

实际程序不能只考虑正确输入，还要处理类型错误或数据缺失：

```cpp
int id{};
double x{};
double y{};
double velocity{};

if (!(std::cin >> id >> x >> y >> velocity))
{
    std::cerr << "Error: Invalid input.\n";
    return 1;
}
```

`std::cin >> id >> x >> y >> velocity` 会依次读取四个变量，并返回输入流的引用。当流对象用于条件判断时，会根据当前流状态转换为布尔值：

- 所有读取操作成功时，条件为真；
- 任意一次读取失败时，条件为假；
- 外层的 `!` 会将判断结果取反，所以输入失败时进入错误处理分支。

其中：

- `std::cerr` 是标准错误输出流，用于输出错误信息；
- `return 1;` 表示程序因为错误提前结束；
- `return 0;` 通常表示程序正常完成。

如果输入失败后只显示错误信息，却没有通过 `return`、循环或其他控制流程处理，程序仍可能继续使用无效或不完整的数据。

## 9. 综合练习：车辆状态输入与输出

编写一个程序，从终端读取车辆编号、位置和速度，然后输出车辆状态。

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `vehicle_id` | `int` | 车辆编号 |
| `x` | `double` | 横坐标 |
| `y` | `double` | 纵坐标 |
| `velocity` | `double` | 车辆速度 |

本次练习要求：

- 使用 `std::cin` 和 `std::cout` 完成输入输出；
- 检查输入是否成功；
- 当速度等于 `0.0` 时输出 `STOP`，否则输出 `MOVING`。

完整代码如下：

```cpp
#include <iostream>

int main()
{
    int vehicle_id{};
    double x{};
    double y{};
    double velocity{};

    std::cout << "Please enter ID, x, y, velocity:\n";

    if (!(std::cin >> vehicle_id >> x >> y >> velocity))
    {
        std::cerr << "Error: Invalid input.\n";
        return 1;
    }

    std::cout << "Vehicle ID: " << vehicle_id << '\n';
    std::cout << "Position: (" << x << ", " << y << ")\n";
    std::cout << "Vehicle velocity: " << velocity << '\n';

    if (velocity == 0.0)
    {
        std::cout << "Status: STOP\n";
    }
    else
    {
        std::cout << "Status: MOVING\n";
    }

    return 0;
}
```

输入：

```text
1 2.5 3.6 0.0
```

输出：

```text
Vehicle ID: 1
Position: (2.5, 3.6)
Vehicle velocity: 0
Status: STOP
```

如果输入：

```text
1 2.5 3.6 0.2
```

程序会输出：

```text
Vehicle ID: 1
Position: (2.5, 3.6)
Vehicle velocity: 0.2
Status: MOVING
```

如果输入了错误的数据类型：

```text
1 abc 3.6 0.0
```

程序会在读取 `x` 时失败，并输出：

```text
Error: Invalid input.
```

随后通过 `return 1;` 结束，不再输出车辆状态。

### 编译和运行

在 Windows PowerShell 中执行：

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic 1.cpp -o 1.exe
.\1.exe
```

参数含义：

- `-std=c++17`：使用 C++17 标准；
- `-Wall`：开启一组常用警告；
- `-Wextra`：开启更多有价值的警告；
- `-pedantic`：检查不符合所选语言标准的扩展用法；
- `-o 1.exe`：指定生成的可执行文件名称。

本题根据要求直接使用 `velocity == 0.0` 判断停车状态。实际工程中的浮点数可能来自计算过程并带有精度误差，因此通常需要根据业务含义设置容差，而不是始终与 `0.0` 做精确比较。

## 10. 本篇总结

这次学习可以归纳为以下几点：

- 使用 `{}` 可以为普通数值变量提供明确初始值，并阻止部分窄化转换；
- `std::cout` 用于标准输出，`std::cin` 用于格式化输入；
- `std` 是标准库命名空间，`::` 用于指定名称所属的作用域；
- `<<` 和 `>>` 在流操作中的含义来自运算符重载；
- 流操作会返回流对象的引用，因此能够连续使用 `<<` 或 `>>`；
- 数值输入默认跳过空格、换行符和制表符；
- 输入内容无法转换为目标类型时，输入流会进入失败状态；
- 完整的控制台程序应当检查输入结果，并在失败时明确处理错误。

通过车辆状态程序，可以初步建立变量初始化、输入检查、输出组织和错误处理的规范编程习惯。
